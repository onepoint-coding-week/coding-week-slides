One app

A Secret Santa app, built by all of you!

The frame is already written. Each team builds one page, in its own folder.

Minutage : 2:00 (cumul 2:30).

L'application permet à des groupes (collègues, famille, amis) d'organiser un Secret Santa : chacun rejoint un groupe, écrit sa liste de souhaits, un tirage décide qui offre à qui.

Nous avons écrit le cadre : le menu, la barre latérale, la base de données et les données de démo. Chaque équipe écrit une feature, et chaque feature devient une page du menu. Une équipe en retard ne bloque personne : une feature pas encore finie n'apparaît simplement pas.

Your folder

The logic, the page and the specification (tests).

app/features/05_greeting_card/logic.py The functions that do the work. you write it · tested
app/features/05_greeting_card/page.py The web page: widgets that call logic.py. you write it
tests/test_05_greeting_card.py Each test is a sentence: what your code must do. already written

Minutage : 4:00 (cumul 6:30).

Prendre l'exemple d'une feature, 05_greeting_card ; chacun remplace par la sienne.

  • logic.py : des fonctions Python simples, sans Streamlit. Elles reçoivent la base et des valeurs, elles renvoient des valeurs. C'est là qu'ils vont passer la semaine, et c'est ce que les tests vérifient.
  • page.py : la page web. Des widgets, des appels aux fonctions de logic.py, l'affichage du résultat. Rien de plus.
  • tests/test_05_greeting_card.py : déjà écrit. Chaque test est une phrase qui dit ce que leur code doit faire. C'est leur cahier des charges. Au départ, tout est « skipped », parce que logic.py n'existe pas encore. On y revient à 14h00, avec le kata TDD.

Pourquoi séparer ? Une fonction sans interface se teste et se comprend facilement. Une fois logic.py juste, la page n'est presque que de l'assemblage.

The data you share

Four tables, already full of demo data. Use them but never change them.

groups a Secret Santa: name, budget, deadline
participants a person in a group
wishes one gift idea on a wishlist
assignments the draw: who gives to whom

Need more? Create your own table, named after your feature: budget_tracker_expenses

No SQL needed: find, insert, update, delete, all in tables.py

Minutage : 3:00 (cumul 9:30).

Quatre tables partagées par toutes les features, remplies au démarrage avec trois groupes de démo : Office party, Family Christmas, Book club.

  • groups : un Secret Santa, avec son budget et sa date limite ;
  • participants : une personne dans un groupe ;
  • wishes : une idée de cadeau sur une liste de souhaits ;
  • assignments : le résultat du tirage, qui offre à qui.

Deux règles :

  • On ne modifie jamais ces tables : ni colonne ajoutée, ni renommage. Besoin de stocker autre chose ? Sa propre table, dont le nom commence par le nom de la feature, par exemple budget_tracker_expenses.
  • Pour lire et écrire : les fonctions de tables.py, find, insert, update, delete. Pas besoin d'écrire de SQL.

Si l'application ne démarre pas sur une machine : le stand « Dr ordinateur » à 12h30, pas maintenant.

Streamlit in one idea

Web pages in plain Python. No HTML, no CSS.

Every click runs your page again, from top to bottom.

A plain variable is lost after a click. What must last goes into the database.

st.text_input a box to type in
st.button True on the click
st.dataframe a table
st.success a green message
st.info explain what's missing

Minutage : 5:00 (cumul 24:30).

Ils ne connaissent pas Streamlit. Une seule idée à retenir : à chaque clic, le script de la page est relancé en entier, de haut en bas. Une variable ordinaire ne survit donc pas à un clic. Ce qui doit durer va dans la base de données (ou dans st.session_state). Cette idée explique presque toutes les surprises de la semaine.

Puis les cinq fonctions à connaître, montrées en direct dans la page de 00_example si le temps le permet.
