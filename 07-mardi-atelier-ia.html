Inside the box

ChatGPT, Claude, Copilot, Gemini... Different names, the same engine : a language model.

Minutage : 0:30.

Demander à main levée : qui a déjà utilisé ChatGPT ? Claude ? Copilot ? Presque tout le monde. Qui sait ce qui se passe quand on appuie sur Entrée ? Beaucoup moins. C'est l'objet de la première partie.

A very good guesser

A language model does one thing: guess the next word.

"Merry Christmas and a happy ..."

New Year 92 %
holiday 5 %
birthday 1 %
  1. Read the text so far.
  2. Guess the most likely next word.
  3. Add it. Start again.

It doesn't know. It predicts.

Minutage : 3:00.

Lire la phrase de gauche et faire compléter la salle : « New Year ». Le modèle fait exactement ça, avec des probabilités apprises sur une énorme quantité de textes. Il choisit un mot, l'ajoute, et recommence. Une réponse entière, c'est cette boucle, mot après mot.

Précision : il travaille sur des « tokens », des morceaux de mots (environ 3/4 de mot en anglais). C'est aussi l'unité dans laquelle on paye et on mesure les limites.

Le message : il ne « sait » pas, il prédit ce qui est plausible. Très souvent juste, parfois faux, toujours avec le même aplomb.

The model's memory: the context

The model sees one thing: the text sent with your question.

Hidden instructions system prompt + tools definitions
The conversation so far every message, both ways
Files everything that you load or paste
Your question every new prompt

Minutage : 3:00.

Le « contexte », c'est tout le texte envoyé au modèle à chaque message : les instructions cachées de l'outil, toute la conversation, les fichiers collés, et la question.

The model's memory: its limits

Anything outside that text does not exist for it.

New chat? It remembers nothing.
Your project? It has never seen it. Paste what matters.
Very long chat? Crucial informations may get lost.

Le modèle n'a pas d'autre mémoire. Il ne connaît pas leur projet, il n'a pas vu leur code, sauf ce qu'on lui colle.

Conséquences pratiques :

  • une nouvelle conversation repart de zéro ;
  • le contexte a une taille maximale : une très longue conversation finit par perdre ses débuts ;
  • pour qu'il respecte les conventions du projet, il faut les lui donner (par exemple coller les tests, ou le guide étudiant).

The prompt is the spec

A vague question gets a vague answer.

"write a Secret Santa draw in Python"

It will guess everything.

Tools: hands for the model

The model can't do anything. It can only ask.

  1. Model: "Call run_tests"
  2. Program: runs the tests
  3. Result: "2 failed"
  4. Model: reads it, goes on

def run_tests(path: str) -> str:
    """Run pytest on this folder. Return the summary."""

The docstring is all the model knows about a tool.

Minutage : 3:00.

Un modèle ne fait que produire du texte. Pour agir, on lui décrit des « outils » : un nom, une description, des paramètres. Quand il en a besoin, il répond par une demande : « appelle run_tests ». C'est le programme autour de lui qui exécute vraiment l'outil, puis lui renvoie le résultat. Le modèle continue avec ce résultat.

Exemple du quotidien : quand ChatGPT « cherche sur le web », c'est un outil de recherche appelé pour lui.

Point clé pour jeudi : la description de l'outil est tout ce que le modèle en sait. Une description floue, et l'outil n'est jamais appelé.

An agent is a loop

Give it a goal. It calls tools until the goal is reached.

Goal → Pick a tool → Read the result → Done? (no: again)

Goal: "make test_draw pass"


1 read_file('logic.py')
2 run_tests('tests/')
  -> 1 failed: KeyError
3 write_file('logic.py', ...)
4 run_tests('tests/')
  -> all passed. Stop.

It acts on your files: read git diff before you commit.

Minutage : 4:00.

Un agent = un modèle + des outils + une boucle. On lui donne un objectif. À chaque tour, il choisit un outil, lit le résultat, et décide de la suite. Il s'arrête quand l'objectif est atteint, ou après un nombre maximum de tours (10 jeudi).

L'exemple de droite est exactement l'atelier de jeudi : « fais passer ce test ». Il lit le fichier, lance les tests, voit l'erreur, corrige, relance.

Exemples connus : Claude Code, GitHub Copilot en mode agent, Cursor. Ce ne sont pas de la magie : c'est cette boucle.

Ce qui change avec un agent : il agit sur leurs fichiers. Donc on relit git diff avant de commiter. Toujours.

Skills: know-how on demand

A folder of instructions the agent opens only when it needs it.


# skills/secret-santa-feature/SKILL.md
---
name: secret-santa-feature
description: Write a feature of the
  Secret Santa app.
---
- Only edit app/features/<yours>/
- Rules go in logic.py, tested
- Never show who gives to whom
At start The agent reads only the description.
When it fits It opens the skill and follows it.
Why The context stays small and clean.

MCP: a USB port for AI

One standard way to plug tools and data into any AI app.

Claude, ChatGPT, VS Code → MCP → GitHub, Google Drive, A database

Example: "List my open pull requests" → the GitHub MCP server answers.

Plugging a server in gives the AI rights. Only trusted ones.

Minutage : 3:00.

MCP, Model Context Protocol : un standard ouvert, publié par Anthropic fin 2024, repris depuis par la plupart des outils (Claude, ChatGPT, VS Code, Cursor...). Avant, chaque outil d'IA devait écrire son propre connecteur pour GitHub, pour Google Drive, pour une base de données. Avec MCP, on écrit un « serveur MCP » une seule fois, et toutes les applis compatibles peuvent s'y brancher. L'image : le port USB-C.

Un serveur MCP propose des outils (au sens de la slide 8) et des données.

Exemple : le serveur MCP de GitHub. Branché sur son assistant, on peut demander « liste mes pull requests ouvertes » : l'assistant appelle l'outil du serveur, qui interroge GitHub.

Attention : brancher un serveur MCP, c'est donner des droits à l'IA. Ne brancher que des serveurs de confiance.
